# 🚗 Concesionario Sport App

App móvil desarrollada con **React Native** y **Expo** que permite a los clientes comprar autos desde la comodidad de su casa. Ofrece un catálogo amplio de marcas para elegir, con registro obligatorio de usuario para poder acceder a la compra y visualización de los vehículos.

> 🛠️ La opción para **vender** autos está en desarrollo. Por el momento la app permite únicamente la compra.

---

## 🚀 Tecnologías Utilizadas

- 📱 React Native
- ⚡ Expo
- 🧭 React Navigation (bottom-tabs, native-stack)
- 🗃️ Redux Toolkit (manejo de estado global)
- 📍 Expo Location + Geolib (geolocalización)
- 🗄️ Expo SQLite (persistencia local)
- 🖼️ Expo Image Picker
- ✅ Yup (validación de formularios)

---

## ⚙️ Instalación y Uso

1. **Cloná el repositorio**
```bash
git clone https://github.com/IgnacioRojos/app-concesionario.git
cd app-concesionario
```

2. **Instalá las dependencias**
```bash
npm install
```

3. **Iniciá el proyecto**
```bash
npx expo start
```

> Para recargar la app manualmente, presioná la tecla `r` en la terminal donde corre Expo.

4. **Ejecutá en un emulador Android** (o escaneá el código QR con la app Expo Go en tu celular).
